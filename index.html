How the physics works

Values are approximate; the simulator uses a simple, ideal physics model.

Free fall from rest
t = √(2h/g)
v = √(2gh)
h = drop height, g = gravitational acceleration
Vertical jump
h_max = v₀²/(2g)
t_air = 2v₀/g
v₀ = launch speed, with landing at launch height
Escape velocity
v_escape = √(2GM/R)
G = gravitational constant, M = planetary mass, R = radius
Weight vs. mass
W = mg
Mass remains constant; weight changes with gravity.

Planetary mass and radius are rounded reference values. Surface gravity is calculated using GM/R², while escape velocity uses √(2GM/R). Real-world motion differs due to atmospheres, rotation, variable gravity, and terrain. The jump simulator assumes a vertical launch with the same initial speed on every planet.
